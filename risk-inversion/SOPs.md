# SOP-016 → SOP-020

## SOP-016 — Runtime Identity Control Protocol
Every consequential agent action must carry an explicit intent, scoped resource/action, expiry and policy identifier. Default is DENY. A kill switch must deny execution. This module provides the contract; production credential brokering and runtime enforcement remain integration work until independently evidenced.

## SOP-017 — Agent Evaluation & Golden Set Management
Maintain versioned golden cases for consequential agent behaviours. Run deterministic checks before promotion and record actual output, expected output, pass/fail and evidence. Production feedback must become evaluation input rather than silently changing policy.

## SOP-018 — Active Memory Reconstruction Protocol
Memory reconstruction follows Cue → Tag → Content. Retrieval must record the cue, selected tags, source/content identifiers and pruning decision. Memory is treated as an evidence-bearing retrieval layer, not unquestioned truth. Retention and deletion rules remain policy-controlled.

## SOP-019 — AI Governance Reporting
Maintain an AI Register containing agent identity, owner, purpose, capabilities, data classes, connected systems, risk classification, controls, evaluation status, evidence status and human accountable owner. Produce periodic governance reports from recorded evidence. Legal/regulatory mappings require current authoritative-source verification.

## SOP-020 — Human Override & Escalation Matrix
Human approval is mandatory for defined consequential actions. Overrides are recorded with requester, target, decision, reason, approver and execution evidence. Incident escalation uses severity and business impact. AI recommendations never substitute for a required human legal/corporate decision.

## Control status
SOP existence is not operational compliance. Promotion is:
EXISTS → WORKS → VERIFIED → LIVE.
